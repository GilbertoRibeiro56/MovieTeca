# Contribuindo com o MovieTeca

Obrigado pelo interesse em melhorar o MovieTeca!

Para contribuir: abra uma *issue* descrevendo o problema ou a melhoria, faça um *fork*, implemente a mudança e envie um *pull request*. Use nomes genéricos e dados fictícios nos exemplos.

Antes de enviar, execute `node tests/backend.test.js` e, se tiver Playwright/Chromium, `python tests/browser.test.py`.

Não inclua no repositório IDs de planilhas particulares, tokens, credenciais, cópias de coleções privadas ou links de implantações pessoais.
